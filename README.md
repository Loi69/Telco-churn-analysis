# Telco Customer Churn Analysis

# Project Overview
This project analyzes customer churn in a telecommunications company 
using Python. The goal is to provide actionable insights to reduce 
churn and improve customer retention.

# Dataset
Telco Customer Churn Dataset with 7,043 customers and 21 features 
including tenure, monthly charges, and churn status.

# Tasks Completed
- Task 1: Data Overview, Sorting & Filtering
- Task 2: Churn Count Visualization (Column Chart)
- Task 3: Monthly Charges Distribution (Histogram)
- Task 4: Churn Rates by Gender (Clustered Bar Chart)# Key Insights
- 1,869 out of 7,043 customers churned (26.5% churn rate)
- Churn is almost equal between Male and Female customers
- Monthly charges show two customer groups: low and high spenders
